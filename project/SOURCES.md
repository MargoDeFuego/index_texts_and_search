# Источники и воспроизводимость

В папке `data/corpus/` находятся **20 локальных русскоязычных учебных документов**. Ничего скачивать при запуске не нужно.

Для каждого документа сохранён идентификатор и справочный URL в `data/corpus_sources.json`. Тексты являются краткими учебными адаптациями, а не копиями веб-страниц. Это позволяет передавать весь корпус вместе с работой и повторно строить словари полностью offline.

Входное задание сохранено в `assignment/Лабораторная_4.pdf`.
