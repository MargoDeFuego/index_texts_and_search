# Лабораторная работа №4 — исправление опечаток и NER

Проект подготовлен для дисциплины **«Индексирование текстов»** по заданию из `assignment/Лабораторная_4.pdf`.

## Главное: интернет не нужен

В архив уже включены:

- 20 русскоязычных документов корпуса (`data/corpus/`);
- 40 размеченных запросов (`queries_dev.json` и `queries_test.json`);
- словарь словоформ с частотами;
- справочник PERSON / ORG / LOC;
- готовая offline-модель NER `RuTinyNER-Perceptron 1.0.0`;
- результаты экспериментов и итоговой проверки;
- отчёт и краткий текст для защиты.

**Никаких `pip install`, `wget`, `curl`, скачивания моделей или текстов по HTTPS не требуется.** Нужен только уже установленный Python 3.10+.

## Быстрый запуск в VS Code / Windows

1. Распаковать архив в обычную папку без изменения внутренней структуры.
2. Открыть эту папку в VS Code.
3. Открыть терминал: `Terminal -> New Terminal`.
4. Проверить Python:

```bat
python --version
```

5. Запустить все тесты:

```bat
python tests\run_tests.py
```

6. Запустить итоговую оценку:

```bat
python src\main.py evaluate
```

Можно просто дважды открыть `run_tests.bat` или `run_evaluation.bat`.

## Один запрос

```bat
python src\main.py query "Найти статьи о Ломоносве в Маскве" --recognizer rule --order A --threshold 2
```

Модельный распознаватель:

```bat
python src\main.py query "Показать офис Яднекс в Москве" --recognizer model --order B --threshold 2
```

Параметры:

- `--recognizer rule|model` — справочник+правила или offline-модель;
- `--order A|B` — порядок обработки;
- `--threshold 1|2` — порог Левенштейна;
- `--no-frequencies` — не использовать частоты при ранжировании;
- `--no-protection` — для B отключить защиту найденных сущностей;
- `--output result.json` — сохранить результат.

## Обработка файла

```bat
python src\main.py file data\queries_test.json --recognizer rule --order A --threshold 2 --output results\my_output.json
```

## Левенштейн отдельно

```bat
python src\main.py distance Яднекс Яндекс
```

Результат `2`: обычное расстояние Левенштейна не считает перестановку соседних букв одной операцией.

## Данные

В каждом из двух наборов по 20 запросов:

| Группа | dev | test |
|---|---:|---:|
| Без ошибок | 5 | 5 |
| Ошибки в обычных словах | 5 | 5 |
| Ошибки в сущностях | 5 | 5 |
| Редкие корректные имена/названия | 5 | 5 |

Каждая JSON-запись содержит:

- `original_text`;
- `correct_text`;
- `typos` с диапазоном исходного ошибочного токена;
- `original_entities`;
- `correct_entities`;
- тип сущности `PERSON`, `ORG` или `LOC`;
- границы `[start, end)`.

Границы автоматически проверяются в `tests/test_data.py`.

## Нормализация

Политика записана в `data/normalization_rules.json`:

- ключи словаря приводятся к нижнему регистру;
- `ё` и `е` эквивалентны при поиске;
- дефисы сохраняются;
- сокращения и верхний регистр сохраняются для отображения;
- стоп-слова из запроса не удаляются;
- итоговый `test` не используется для пополнения словарей и выбора параметров.

## Корректор

`src/lab4/levenshtein.py` содержит самостоятельную реализацию Левенштейна.

Для неизвестного токена:

1. ищутся кандидаты в `word_dictionary.json`;
2. фильтр — расстояние не выше заданного порога;
3. сортировка: расстояние по возрастанию, частота по убыванию, затем алфавит;
4. выводится до трёх кандидатов;
5. top-1 применяется как предлагаемое исправление.

## Два NER-подхода

### 1. Справочник + правила

`src/lab4/ner_rule.py`:

- ищет формы из `entity_dictionary.json` без учёта регистра;
- проверяет границы слов;
- при перекрытии выбирает наиболее длинное совпадение;
- содержит контекстное правило после маркеров `компания`, `университет`, `завод`, `город`, `профессор` и др.

### 2. Готовая offline-модель

`models/rutiny_ner_v1.json` — **RuTinyNER-Perceptron 1.0.0**.

Это заранее обученная модель токеновой классификации с averaged perceptron. Основная программа только загружает готовые веса. Подробности — `MODEL_CARD.md`.

## Порядки A и B

**A:** коррекция общего текста -> NER исправленного текста.

**B:** NER исходного текста -> защита найденных диапазонов -> коррекция остальных слов -> повторный NER.

Для подозрительных слов внутри защищённого диапазона программа может показать рекомендации из справочника, но автоматически их не применяет.

## Оценка

`python src\main.py evaluate`:

1. проводит исследования на `queries_dev.json`;
2. выбирает конфигурацию **только по dev**;
3. сохраняет её в `config/final_config.json`;
4. один раз оценивает четыре комбинации на `queries_test.json`;
5. считает:
   - top-1 accuracy исправления;
   - top-3 recall;
   - долю ошибочно изменённых корректных токенов;
   - NER precision / recall / F1;
   - NER-метрики отдельно для PERSON / ORG / LOC.

При исправлениях длина текста может меняться. `map_span()` переносит эталонные границы из исходного текста в исправленный с учётом журнала замен.
