# RuTinyNER-Perceptron 1.0.0

**Назначение:** второй, модельный подход к NER в лабораторной работе №4.

- Язык: русский.
- Метки: `PERSON`, `ORG`, `LOC`, `O`.
- Архитектура: заранее обученный averaged perceptron для токенов с лексическими, префиксно-суффиксными и контекстными признаками.
- Версия весов: `1.0.0`.
- Файл готовой модели: `models/rutiny_ner_v1.json`.
- Источник обучающих данных: независимый каталог сущностей корпуса `data/entity_catalog.json` + детерминированные русские шаблоны из `tools/train_offline_model.py`.
- В основной программе обучение **не выполняется**: модель только загружается и используется для инференса.
- Зависимости: только стандартная библиотека Python.
- Интернет при запуске не нужен.

## Почему модель локальная

Условие пользователя для этой версии проекта — полностью автономный запуск без скачивания моделей и пакетов по HTTPS. Поэтому модель и веса уже включены в архив проекта. Скрипт обучения оставлен исключительно для воспроизводимости и не требуется для защиты.

## Ограничения

Модель компактная учебная, поэтому может ошибаться на новых именах и контекстах. Именно эти ошибки полезны для сравнения со справочным распознавателем и для анализа влияния порядка A/B.
