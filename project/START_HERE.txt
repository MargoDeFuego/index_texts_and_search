ЛАБОРАТОРНАЯ РАБОТА №4 — БЫСТРЫЙ СТАРТ
=========================================

Проект полностью автономный: НИЧЕГО скачивать из интернета не нужно.
Тексты, словари, размеченные запросы, готовая NER-модель, результаты и отчёт уже внутри.

Нужно только, чтобы на компьютере был установлен Python 3.10 или новее.

1) Распакуйте архив.
2) Откройте распакованную папку в VS Code.
3) Terminal -> New Terminal.
4) Выполните:

   python --version
   python tests\run_tests.py
   python src\main.py evaluate

Для демонстрации преподавателю:

   python src\main.py query "Показать офис Яднекс в Москве" --recognizer rule --order A --threshold 2
   python src\main.py query "Показать офис Яднекс в Москве" --recognizer model --order B --threshold 2
   python src\main.py distance Яднекс Яндекс

Также можно запускать файлы двойным щелчком:
- run_tests.bat
- run_evaluation.bat
- run_query.bat

Отчёт: report\Отчет_ЛР4.docx
Краткая защита: report\Защита_кратко.txt
Ответы на вопросы: report\Ответы_на_вопросы.txt

ВАЖНО:
- В основной работе модель уже готова и только загружается из models\rutiny_ner_v1.json.
- tools\train_offline_model.py оставлен только для воспроизводимости и запускать его не нужно.
- Исходное задание лежит в assignment\Лабораторная_4.pdf.
